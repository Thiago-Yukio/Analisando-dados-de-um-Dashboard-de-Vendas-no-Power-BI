# Analisando-dados-de-um-Dashboard-de-Vendas-no-Power-BI

Este projeto foi desenvolvido como parte do desafio "Analisando dados de um Dashboard de Vendas no Power BI", da DIO, com o objetivo de consolidar competências em modelagem de dados, criação de visuais geográficos e análise de rentabilidade por segmento no Power BI. O relatório foca na transformação de dados brutos da planilha Financial Sample.xlsx, especificamente da tabela Financials, em informações visuais acionáveis.
